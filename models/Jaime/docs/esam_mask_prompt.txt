EfficientSAM — Opción 1: Prompt de máscara desde anotaciones Roboflow
=======================================================================

IDEA GENERAL
------------
En lugar de usar las esquinas de la bbox de YOLO como prompt (lo que hace
efficientSAM.ipynb actualmente con labels 2/3), se pasa directamente la
máscara binaria que ya tienes anotada en Roboflow con la polygon tool.
EfficientSAM acepta esto como "mask_inputs", lo que le da la forma exacta
del corte diagonal como punto de partida y produce segmentaciones mucho más
precisas para cut_edge.

QUÉ TIENES AHORA
----------------
- efficientSAM.ipynb: usa YOLO (michelin_v2/v3) para detectar boxes, luego
  pasa las esquinas top-left y bottom-right (labels 2 y 3) a EfficientSAM.
  IoU actual con este método:
    cut_edge:     0.339  (n=363)
    qr_code:      0.522  (n=89)
    rubber_strip: 0.400  (n=67)

- Roboflow: tienes anotaciones de cut_edge hechas con polygon tool que
  luego conviertes a máscara. Esas máscaras son la forma real del corte
  (diagonal, estrecha), no solo su bbox.

POR QUÉ MEJORA
--------------
El bbox de YOLO para un cut_edge es un rectángulo horizontal que incluye
mucho fondo. EfficientSAM intenta segmentar dentro de ese rectángulo pero
sin saber dónde está el borde exacto del corte. Si le pasas la máscara del
polígono ya tiene la forma correcta y solo refina los bordes a nivel de
píxel.

CÓMO EXPORTAR DESDE ROBOFLOW
-----------------------------
En la exportación del proyecto de new_samples_cut_edge, elige el formato:
  - "COCO Segmentation" (JSON con coordenadas de polígono por imagen)
  - O bien "PNG Masks" (una imagen en escala de grises por cada imagen,
    píxeles blancos = objeto, negros = fondo)

El formato PNG Masks es el más directo para pasarlo a EfficientSAM.

PIPELINE EN PYTHON
------------------

1. Cargar la máscara PNG de Roboflow:

    from PIL import Image
    import numpy as np

    mask_png = Image.open("path/to/mask/multimedia_31_jpg.rf.HASH.png")
    mask_np  = np.array(mask_png) > 0   # bool (H, W)

2. Redimensionarla a 256x256 (resolución interna de SAM/EfficientSAM):

    import cv2
    mask_256 = cv2.resize(
        mask_np.astype(np.uint8), (256, 256), interpolation=cv2.INTER_NEAREST
    )
    # tensor shape: (1, 1, 256, 256)
    import torch
    mask_tensor = torch.tensor(mask_256, dtype=torch.float32).unsqueeze(0).unsqueeze(0)

3. Llamar a EfficientSAM con mask_inputs en lugar de (o además de) los puntos:

    with torch.no_grad():
        masks, scores = sam(
            img_tensor,          # (1, 3, H, W) imagen recortada
            pts,                 # puntos opcionales (puedes mantener las esquinas)
            lbl,
            mask_inputs=mask_tensor.to(DEVICE),
        )

    Nota: si no quieres dar ningún punto, pasa pts y lbl vacíos:
        pts = torch.zeros((1, 1, 0, 2), dtype=torch.float32).to(DEVICE)
        lbl = torch.zeros((1, 1, 0),    dtype=torch.int32).to(DEVICE)

4. El resto del código de run_efficient_sam() en efficientSAM.ipynb no cambia:
   se sigue aplicando el threshold (> 0.5), se reconstruye la máscara full-res
   y se pinta el overlay.

LIMITACIÓN IMPORTANTE
---------------------
Las máscaras de Roboflow son ground truth, no son generadas en runtime.
Esto significa que esta mejora solo aplica durante evaluación o cuando el
sistema ya sabe dónde está el corte (por ejemplo, en un flujo donde primero
un operario confirma la detección). En producción sin GT, EfficientSAM
seguiría dependiendo de la bbox de YOLO como único prompt.
